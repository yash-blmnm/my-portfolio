# Minimal React Portfolio

A minimal portfolio built with React, Vite, and Tailwind CSS.

## Structure

- `src/data/profile.js` for your name, links, skills, and experience
- `src/data/projects.js` for project cards
- `src/data/blogs.js` for featured writing
- `src/components` for the page sections

## Run Locally

```bash
npm install
npm run dev
```

## Customize

Update the placeholder values in the data files first. The layout will render projects and blogs automatically from those arrays.
